# Logistics & Delivery Performance Dashboard | Power BI

## Project Overview

This project was developed as **Task 3: Interactive Dashboard** during my Power BI internship at SWYNEX Technologies.

The dashboard provides an interactive view of logistics and delivery performance, helping users analyze sales, profit, order volume, regional performance, and delivery status through clear visualizations and KPI cards.

## Objectives

- Analyze overall sales and profit performance.
- Compare sales across different regions.
- Evaluate profit across products.
- Understand order distribution by delivery status.
- Enable interactive data exploration using slicers.

## Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **DAX** – Measures and KPI calculations
- **Data Modeling** – Organizing data for analysis
- **Data Visualization** – Charts, KPI cards, and slicers

## Dashboard Features

### 1. KPI Cards
- Total Sales
- Total Profit
- Average Sales
- Total Orders

### 2. Sales by Region
A column chart used to compare sales performance across regions.

### 3. Profit by Product
A horizontal bar chart used to compare profit across products.

### 4. Delivery Status Analysis
A donut chart showing the distribution of orders across delivery statuses, including Delivered, Cancelled, and In Transit.

### 5. Interactive Slicers
- Region
- Delivery Status

These slicers allow users to filter the dashboard and explore different segments of the logistics data.

## Key Learnings

- Designing an interactive Power BI dashboard.
- Presenting business metrics using KPI cards.
- Selecting appropriate charts for data comparison.
- Using slicers to support interactive analysis.
- Improving dashboard layout and readability.
